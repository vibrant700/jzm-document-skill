# jzm-document-skill

面向中文技术报告与课程作业的 Codex 技能。通过完整范文学习排版、结构、句式和自然表达，围绕本次材料组织过程、证据、原理与结论。

## 三种模式

| 模式 | 组织方式 | 范文 |
| --- | --- | --- |
| 流程梳理式 | 按处理步骤展开，解释操作、原理与结果 | 钱币定位报告 |
| 全问答式 | 按题目与子问题逐项回答、推导和解释 | A2、智能计算作业第三章 |
| 融合式 | 按任务或实验主题串起过程、结果与机制分析 | A1、A3、A4 |

## 调用流程

1. 选择模式。
2. 流程梳理式继续选择是否加入函数说明。
3. 最后选择 PDF、Word、PDF + Word，或自行输入其他格式。

已经明确的选项不重复询问。写作前必须将对应模式的**范文全文**载入上下文，并检查原件排版；不能用摘要或节选替代。只借鉴写法，不移用范文的具体内容、数据或结论。

## 安装与使用

将本仓库完整放入 `~/.codex/skills/jzm-document-skill`，或自定义 `CODEX_HOME` 下的 `skills/jzm-document-skill`。保留 `references/examples/` 中的六份 DOCX 原件。

显式调用即可开始：

```text
$jzm-document-skill 请根据我提供的题目、代码和实验结果撰写报告。
```

也可以直接指定选项：

```text
$jzm-document-skill 采用融合式，输出 PDF + Word。
```

技能仅在显式调用时启用。详细规则见 [SKILL.md](SKILL.md)；运行环境需具备读取 DOCX、检查版面及生成所选格式的能力。
